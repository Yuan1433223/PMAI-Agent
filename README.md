# PMAI-Agent

面向应届生的企业发现与招聘线索调查项目。从公开企业来源扩大候选范围，保留岗位线索的依据与未知项，供使用者自行决定下一步。

首个场景：深圳 Agent 开发、大模型应用及相关 FDE 机会。与现有招聘软件互补，不自动投递、修改简历或承诺录用，也不声称找全城市所有机会。

## 当前状态

开发准备阶段：已整理需求、架构与数据模型草案；尚无可运行程序，未配置模型账户、执行付费调查或部署服务。技术选型仍待首个切片验证。
